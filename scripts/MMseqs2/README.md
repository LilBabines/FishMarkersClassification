# MMseqs2 

## Setup

1. Follow the official installation guide: [MMseqs2 Documentation](https://mmseqs.com/latest/userguide.pdf)
2. Convert data csv to .fasta file : run `python table_tot_fasta.py` (package required : pandas, numpy, ete3, you can use the venv created for [Bouillabert](../DNABert2/requirements.txt) )

## Execution 

Run the script:

```bash
./run_mmseqs2_v4.sh
```
